# tas-kagit-makas-oyunu 🪨📃✂️
Bu Python projesi, klasik "Taş-Kağıt-Makas" oyununu terminal üzerinden oynayabileceğiniz bir uygulamadır.
Bilgisayar ve kullanıcı birbirleriyle karşılaşır ve 2 tur kazanan oyunun galibi olur!

# Projenin Özellikleri 🔦

Kullanıcı ve bilgisayar rastgele "Taş", "Kağıt" veya "Makas" seçer.

3 tur oynanır, 2 tur kazanan oyunun galibi olur.

Bilgisayar bazen oyun oynamak istemeyebilir :)

Kullanıcı, oyunun sonunda tekrar oynayabilir.

# Projenin Amacı 🎯
Bu proje Aygaz Python Bootcamp programının bitirme projesiydi ve 1 aylık bir süreç sonucunda edindiğim blgilerle yaptığım temel seviyede taş kağıt makas oyunudur. 
Python dilinde temel olarak kullandığımız yapıları içerir.

# Pythonda Kullanılan Yapılar 💻
Bu projede Python'un şu temel özellikleri ve kuralları kullanılmıştır:

Koşullu İfadeler (if-elif-else): Oyunun kurallarını uygulamak için kullanıldı.

Döngüler (while): Oyun ve turların devam etmesini sağlamak için kullanıldı.

Fonksiyonlar: Kod tekrarını önlemek ve düzenli hale getirmek için kullanıldı.

Kullanıcı Girişi (input): Oyuncudan veri almak için kullanıldı.

String Metodları (lower): Kullanıcı girişini normalize etmek için kullanıldı.

Rastgele Seçim (random.choice): Bilgisayarın rastgele seçim yapmasını sağlamak için kullanıldı.
